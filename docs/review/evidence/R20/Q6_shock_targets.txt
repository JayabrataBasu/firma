     random subset:  NOT expressible by the plugin. shock.stochastic's `targets` is a fixed
                     field copied into the drawn shock (firma-plugin-shock/src/lib.rs:400-401,
                     :459 `targets: self.p.targets.clone()`); only onset and magnitude are drawn.
                     A random subset could only be produced OUTSIDE the engine, by a config
                     generator writing a per-seed {"kind":"set","ids":[...]}.

     Regulatory   (:151-160): writes ONE AdjustGlobalReal on theta_limit / theta_cap.
                  `targets` is NOT read. theta is global (ADR-0015), so a regulatory shock
                  always reaches every firm, whatever `targets` says.
     Reputational (:162-180): per-agent legitimacy delta, `if shock.targets.hits(a.0)` (:166).
                  This is the ONLY channel that honours `targets`.
     Resource / Competitive (:181-193): ONE AdjustGlobalInt on input_price / output_price.
                  `targets` is NOT read.

   by the JSON schema but has no effect; a subset shock is possible today only on the
   reputational channel. Not executed here: this is from reading the code, not from a run.
